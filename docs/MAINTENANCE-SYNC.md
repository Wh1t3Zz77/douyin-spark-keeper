## 好友与历史数据

昵称、备注和抖音号用于显示和搜索，不能代替稳定收件身份。计划和运行明细记录 Contact 本地 ID 与稳定身份快照；同步读取聊天页及被动资料响应，不为好友批量打开主页，发送前和打开会话后均核验身份。

启动时迁移身份相关字段和计划好友唯一约束。请先备份数据卷；遇到“缺少稳定好友标识”时，重新同步、从明确的好友记录重新选择并保存计划。系统不会仅凭旧昵称自动猜测收件对象。最近列表保留已选好友和计划引用，历史记录仍保存在数据库用于绑定与审计。

总览只在同一计划内对可唯一对应的旧名称记录做兼容，显式不同 ID 不按同名匹配。当天已提交发送不会被后续失败记录覆盖。

## 通知

用户继续通过自己的通知设置选择是否收邮件。可配置 `TASK_FAILURE_ADMIN_EMAIL` 让部署管理员独立接收终止失败通知；留空则关闭管理通知，与 `ADMIN_EMAIL` 的登录身份设置互不影响。

首次执行加两次重试，共最多 3 次尝试，重试中不发送失败邮件。登录失效、安全验证、身份缺失和不确定结果等停止执行后通知。按运行失败事件去重；同一收件邮箱不发两份。不同失败计划可以分别通知，不启用账号级每日失败合并或全部计划结束后的失败汇总。

## 执行与部署

worker 使用独立任务进程，1200 秒整次任务硬超时，退出时清理进程组。不确定发送结果不会自动重试。Compose 保留 init，worker 内存及内存加交换空间均为 900 MiB；API 为 300 MiB，前端为 260 MiB。

小内存服务器应先在其他机器构建，或使用 `docker compose build api`、`docker compose build frontend` 分别串行构建；不要同时构建多个服务。升级前确认没有正常任务正在执行，备份数据库并保留回滚镜像。回滚代码时不要恢复旧数据库覆盖新执行记录。

## 备案页脚

在 `.env` 中填写自己的完整备案号：

```dotenv
NEXT_PUBLIC_ICP_NUMBER=你的完整ICP备案号
NEXT_PUBLIC_PUBLIC_SECURITY_NUMBER=你的完整公安备案号
```

公安号应含 14 位备案数字。前端自动生成 `https://beian.mps.gov.cn/#/query/webSearch?code=备案数字`，原比例图标位于编号前。ICP 号链接到 `https://beian.miit.gov.cn/`。默认留空，不给未备案或他人部署的域名标注作者站点编号。

修改后重新构建前端，配置会写入公开的页面资源。作者站点使用的编号是“浙ICP备2026076430号-1”和“浙公网安备33010602015002号”，仅用于其已批准的域名。
